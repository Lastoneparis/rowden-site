Rowden Support

Rowden is a fast mobile client for your Postgres / Supabase projects — browse and edit tables, view auth users and storage, run SQL, and check analytics on the go. Unofficial client, not affiliated with Supabase.

Getting started

  1. Try the built-in Demo Project to explore Rowden with no setup.
  2. In Settings → Projects, add your project URL and API key (stored in the Keychain).
  3. Open Tables to browse and edit rows, or use the SQL editor and analytics.

Frequently asked

Which databases? Postgres databases, including Supabase projects, via their API.

Is my data private? Yes — Rowden connects directly from your device to your project. See our Privacy Policy.

What does Premium add? Multiple projects, editing rows, the SQL editor, and storage upload.

Restore a purchase? Settings → Restore Purchases.
